# MoonBot Touch — Bot Dofus Touch Cloud

- Site officiel : https://moon-bot.io/touch/

**MoonBot Touch** est une plateforme cloud d’automatisation pour **Dofus Touch**, conçue pour gérer les combats, la récolte, le craft, l’hôtel de vente, les trajets, le scripting Lua et le multi-comptes depuis une interface web moderne.

MoonBot Touch permet de piloter ses bots directement depuis un navigateur, sans installation locale, sans VPS et sans machine puissante. L’objectif est simple : offrir un environnement complet, scalable et accessible pour automatiser et superviser ses comptes Dofus Touch en temps réel.

## Fonctionnalités principales

### Combat intelligent

MoonBot Touch intègre une IA de combat configurable avec gestion des sorts, ciblage avancé, placement stratégique, invocations, défis, auto-boost des sorts et des caractéristiques. Le système est pensé pour s’adapter à toutes les classes de Dofus Touch.

### Récolte automatique

Automatisez la récolte de ressources avec gestion des pods, whitelist, blacklist, retour banque automatique et déplacement intelligent. MoonBot Touch facilite les sessions longues de farm tout en gardant un contrôle précis sur les ressources collectées.

### Vente HDV automatique

MoonBot Touch propose un système avancé de vente en hôtel de vente avec ajustement automatique des prix, choix intelligent des lots x1, x10 ou x100, prix plancher fixe ou basé sur le prix moyen, et gestion des items prioritaires.

### Artisanat automatique

Le module de craft détecte les ateliers disponibles, calcule le nombre maximum d’objets craftables, dépose les ingrédients nécessaires et lance la production en série. Tous les métiers sont pris en charge.

### Multi-comptes et groupes coordonnés

Gérez plusieurs comptes Dofus Touch depuis une seule interface. MoonBot Touch permet la connexion et déconnexion en masse, le lancement de scripts sur plusieurs bots, la coordination leader + mules, le déplacement synchronisé et les combats en équipe.

### Scripting Lua complet

MoonBot Touch dispose d’une API Lua complète pour créer des scripts personnalisés : combat, déplacement, inventaire, PNJ, banque, HDV, craft, quêtes, montures, échanges et plus encore.

Chaque script peut définir des trajets, des stratégies de combat, des actions de récolte, des retours banque, des ventes HDV ou des comportements personnalisés.

### World Pathfinding

Le système de pathfinding permet une navigation automatique entre les maps avec gestion des zaaps, zaapis, portes et trajets complexes. MoonBot Touch peut également gérer le mode fantôme avec retour phénix automatique.

### Dashboard web moderne

MoonBot Touch est pilotable depuis un dashboard web complet incluant :

- vue carte du monde ;
- monitoring en temps réel ;
- logs et chat ;
- statistiques détaillées ;
- éditeur de scripts ;
- configuration visuelle du combat ;
- gestion de la banque ;
- configuration HDV ;
- gestion du craft ;
- outils de scripting Lua.

## Technologies et concepts

MoonBot Touch s’appuie sur une architecture cloud permettant d’exécuter et de superviser plusieurs bots en parallèle. La plateforme centralise le contrôle des comptes, scripts, groupes, trajets et modules métiers depuis une interface unique.

L’environnement Lua permet aux utilisateurs avancés de créer leurs propres scripts, tandis que le dashboard facilite la gestion quotidienne des bots, même sans configuration complexe.
